
# SCOUT Git & GitHub Class

Welcome to the **SCOUT Git & GitHub Class Repository**! 

This repository contains the learning materials, practical assignments, cheat sheets, and resources for the SCOUT Git & GitHub sessions.

The goal of this class is not just to learn what Git and GitHub are, but to **use them practically** to manage projects, collaborate with others, and build a professional online presence.

---

## 🎯 Learning Objectives

By the end of this class, students should be able to:

- Understand the concept of version control
- Understand the difference between **Git** and **GitHub**
- Install and configure Git
- Create and manage Git repositories
- Track changes using Git
- Create meaningful commits
- Work with branches
- Merge changes
- Push projects to GitHub
- Clone and pull repositories
- Create and manage GitHub repositories
- Write and edit Markdown files
- Create professional `README.md` files
- Collaborate with others using Git and GitHub
- Create a personal portfolio landing page
- Publish a portfolio landing page using **GitHub Pages**
- Use GitHub to showcase projects, skills, and learning progress

---

## 🌐 Build Your Portfolio Landing Page

As part of the practical component of this class, students will create a simple **personal portfolio landing page** and publish it online using GitHub Pages.

Your portfolio can include:

- 👋Introduction
- 🧑🏽‍💻 About Me
-  Skills
- 📂 Projects
- 🎓 Education
- 📜 Certifications
- 📫 Contact Information
- 🔗 LinkedIn and GitHub links

By the end of the class, you should have a **live portfolio page** that you can share with:

- Recruiters
- Employers
- Potential collaborators
- Other professionals
- Friends and colleagues

> **Your GitHub should not only contain your code. It should tell people what you can do.**
